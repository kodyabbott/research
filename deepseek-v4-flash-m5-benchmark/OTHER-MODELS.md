# Additional models worth evaluating on this M5 Max

Researched September 22, 2026. The earlier shortlist was selective. These are additional candidates, not winners demonstrated by this Mac's benchmarks. My strongest additions to the general-purpose shortlist are **Muse Glimmer 30B** and **Nemotron 3 Super**; for fast interaction, add **LFM2-24B**. Compare them with the previously recommended Qwen3.8-27B and Qwen3.6-35B, using representative tasks.

The sizes below are summed `.safetensors` bytes from pinned Hugging Face revisions, in decimal GB. They exclude cache, runtime buffers, the operating system, and other applications. A model's advertised context length does not guarantee that context fits on this laptop. None of these additional models was downloaded or tested here during the DeepSeek evaluation.

One particularly relevant external speed result: Meta reports **26.6 tok/s without speculation and 50.2 tok/s with DFlash on an M5 Max**, using its K-Quant-17GB Muse Glimmer configuration. That is a different artifact and protocol from the 8-bit MLX candidate above, and it is **not a measurement on this host**. It makes Muse a useful speed/quality experiment, not a guaranteed 50 tok/s download. [Meta's benchmark table](https://huggingface.co/meta-models/Muse-Glimmer-30B#optimized-for-local-deployments).

The checked MiniMax M2.7 **4-bit** artifact is **128.667 GB**, leaving insufficient practical space for a comfortably resident desktop workload; its **3-bit** option is the candidate above. MiniMax M3 **4-bit** is **241.481 GB**, beyond this machine's unified memory. [M2.7 4-bit](https://huggingface.co/mlx-community/MiniMax-M2.7-4bit), [M3 4-bit](https://huggingface.co/mlx-community/MiniMax-M3-4bit). Smaller conversions or offloading would be separate experiments with additional quality/speed tradeoffs.

I also checked the [Nemotron TwoTower MLX port](https://huggingface.co/pipenetwork/Nemotron-Labs-TwoTower-30B-A3B-mlx-4bit). It is an interesting diffusion research model requiring a custom runner, but its publisher's M3 Ultra measurements do not support promoting it as the next practical Mac speed winner.

[VISTA-9B](https://huggingface.co/inclusionAI/VISTA-9B) is a screenshot-to-click specialist worth tracking. However, the checked [9.515 GB MLX artifact](https://huggingface.co/pipenetwork/VISTA-9B-MLX-8bit) explicitly contains only the text backbone. It therefore does not establish a usable local screenshot-grounding setup and is excluded from the install shortlist.

Exact revisions and byte totals are preserved in [candidate metadata](candidate-metadata.json). Recommendations are based on documented capabilities and available artifacts; the models must be tested locally before claiming any category winner.
